## Working rules

1. Use the homepage for general product directories, comments, and editorial outreach.
2. Position the product as a practice, explanation, and review tool for SPI, 玉手箱, GAB, and CAB. Do not describe it as an answer-lookup or 解答速報 site.
3. Record every attempt in [submissions.md](submissions.md) before submitting again.
4. Skip paid placements and reciprocal footer-link requirements unless explicitly approved.
5. For blog comments, contribute a genuinely useful reply first and include the homepage once. note.com comment links are nofollow.
6. Do not record passwords in this project. `config.yaml` is listed in `.gitignore` and stays untracked.

## CLI note

Backlink Pilot currently auto-loads the `config.yaml` in the repository root when run from `backlinks`. Confirm that root configuration points to this product before using the CLI. This project-local configuration is kept for project isolation and manual operations.
